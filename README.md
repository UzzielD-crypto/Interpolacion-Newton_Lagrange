# Interpolacion-Newton_Lagrange
# Práctica: Interpolación de Lagrange vs. Diferencias Divididas de Newton

Repositorio correspondiente a la Práctica 1 de la Unidad 5 de la asignatura **Métodos Numéricos** del Instituto Tecnológico Superior de Xalapa (ITSX).

## Descripción del Proyecto
Este proyecto en Java implementa y compara dos de los métodos fundamentales de interpolación polinomial numérica:
1. **Diferencias Divididas de Newton:** Algoritmo base proporcionado por la asignatura para la construcción recursiva del polinomio de interpolación.
2. **Polinomio de Interpolación de Lagrange:** Implementación completada mediante la productoria de los polinomios base L_i(x).

## Requisitos del Entorno
* **Lenguaje:** Java.
* **Entorno de Desarrollo (IDE):** Compatible con IntelliJ IDEA (Compilador que se usa).
* **Sistema Operativo:** Independiente (probado en entornos de desarrollo multiplataforma).
